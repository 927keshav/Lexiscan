# Member 3 — NLP Engine

## Role
Build and maintain the complete NLP pipeline: OCR text extraction, NER model training and prediction, and postprocessing with validation.

## Files
```
3_nlp_engine/
├── ocr_engine.py       # extract_text_from_pdf()
├── train_ner.py        # NER model training (synthetic data)
├── ner_predict.py      # extract_entities()
├── postprocessor.py    # postprocess() — validation & formatting
├── models/legal_ner/   # Trained model (generated, not committed)
└── README.md
```

## Function Signatures
```python
extract_text_from_pdf(pdf_path: str) -> str
extract_entities(text: str) -> list[dict]   # keys: text, label, start, end
postprocess(ner_entities: list) -> dict      # keys: dates, parties, dollar_amounts, termination_clauses
```

## Entity Labels
| Label | Example |
|-------|---------|
| PARTY | "Acme Corp" |
| DATE | "2025-01-15", "March 3, 2024" |
| DOLLAR | "$500,000" |
| TERM_CLAUSE | "30 days written notice" |
